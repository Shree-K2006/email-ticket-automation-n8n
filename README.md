
## 🚀 Project Overview
This project automates customer support ticket handling using n8n.

## ⚙️ Workflow
- Gmail Trigger detects incoming emails
- Switch node classifies priority (Urgent / High / Normal)
- Slack sends alerts to respective teams
- Google Sheets stores ticket data

## 🛠️ Tech Stack
- n8n
- Gmail API
- Slack API
- Google Sheets API

## 🔥 Features
- Real-time email monitoring
- Automatic ticket classification
- Team notifications via Slack
- Data logging in Google Sheets
